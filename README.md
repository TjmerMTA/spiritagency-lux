# lux.spiritagency.space

Сателлит агентства Spirit: лендинг «Менеджмент OnlyFans під ключ» и блог из трёх статей.

- Сайт статический, лежит в `site/` — править можно прямо там.
- Выкладка: `./deploy.sh` заливает `site/` в ветку `gh-pages`, оттуда его отдаёт GitHub Pages.
- Домен: `site/CNAME`. В DNS нужна запись `CNAME lux → tjmermta.github.io`.
- Кнопки заявок ведут в Telegram агентства.

Откуда взят: восстановлен 03.10.2026 из темы WordPress Spirit Satellite — разметка, стили и тексты темы, заголовки как после правки 28.08.2026.
